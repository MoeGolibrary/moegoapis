## 🌐 Domain Structure

The MoeGo APIs are organized into one domain:

```
openapi.moego.pet
```

Each path corresponds to a specific version and resource:

- `/v1/auth`
- `/v1/appointment`
- `/v1/customer`
- `/v1/webhooks`

Each product contains one or more APIs for different use cases such as authentication, data management, and event
notifications.

## 🔄 Webhook Integration

Webhooks allow you to receive real-time updates when certain events occur within the MoeGo system. This provides an
efficient way to integrate external services with the platform.

### 📁 Location:

- [proto file](moego/business/webhook/v1/webhook_service.proto): `moego/business/webhook/v1/webhook_service.proto`
- [webhook.md](docs/webhook.md): API documentation
- [event.md](docs/event.md): Event documentation

### 📌 Features:

- Subscribe to business events like `APPOINTMENT_CREATED`, `APPOINTMENT_FINISHED`. [event.md](docs/event.md)
- Configure delivery endpoints and HMAC signing
- View and retry webhook delivery logs
- Set up test calls for debugging

## 📚 API Documentation

The MoeGo APIs are documented using OpenAPI 3.0. You can find the API documentation in the following files:

- [Authentication](moego/auth/README.md): Authentication is the process of verifying the identity of a user or system
- [Agreement](docs/agreement.md): Agreement is a contract between a business and a customer
- [Appointment](docs/appointment.md): Appointment is a record of a service provided to a customer
- [Block](docs/block.md): Block is a time slot that cannot be booked
- [Business](docs/business.md): Business is a core entity representing a business that provides services to customers
- [Company](docs/company.md): Company is a core entity representing a company that owns a business
- [Customer](docs/customer.md): Customer is a core entity representing clients who use your services
- [Discount](docs/discount.md): Discount is a coupon or other form of payment reduction
- [Online Booking](docs/online_booking.md): Online Booking is a feature that allows customers to book appointments
  online
- [Order](docs/order.md): Order is a record of a purchase made by a customer
- [Payment](docs/payment.md): Payment is a transaction made by a customer
- [Pet](docs/pet.md): Pet represents an animal companion owned by a customer, which receives services at your business
- [Report](docs/report.md): Report is a collection of data generated by MoeGo
- [Review](docs/review.md): Review is a feedback provided by a customer
- [SettingService](docs/setting_service.md): SettingService is a service for managing business settings
- [Webhook](docs/webhook.md): Webhooks allow you to receive real-time updates when certain events occur within the MoeGo
  system

Common Entity Documentation:

- [Address](docs/common/address.md): Address represents a physical location
- [Pagination](docs/common/pagination.md): Pagination represents a page of results
- [Weight](docs/common/weight.md): Weight represents a weight
